# 操作の再生を使う制作候補の比較

2026年11月11日。現行の製品と同じ `PromptMaker`、`CanvasService`、公開契約、Chromium での必須検査、確認保存を基準とした。候補版は検証を `review.mode: "replay"` に設定し、制作担当と独立判定の両方を Luna low に設定した。制作担当は確認したい要件を一つ選び、期待する画面の変化と短い操作を最初の応答で提案できる。

ホストは既存の操作形式で手順を検査し、同じ操作と乱数 seed で候補を再生する。独立した担当に依頼、コード、保存版との差分、再生の観測を渡す。重大な指摘を修正した候補は、元の手順を保存したまま再生する。修正後の記録は再判定済みと扱わず、画面に修正前後の観測を表示する。再生できない候補を改善として選ばない。隔離・必須検査・確認保存には既存の経路を使う。

## 固定条件

- 新規4、部分修正4、修復4、非ゲーム1の新しい2D課題を各3回。両条件に同じ依頼、元作品、seed、ブラウザ採点を適用した。複数ターンの課題は各ターンで保存した作品を個別に採点し、全ターンの合格を必要とする。
- 判定は生成側に渡さない。実行前に正しい参照、既知の不具合、別の正しい実装で対照28件が期待どおりになることを確認し、課題・対照・採点を固定した。
- 1課題180秒、制作は1ターン3呼び出し・課題全体6呼び出しまで、独立した判定は複数ターンを含む課題全体で最大1呼び出し。独立判定の形式エラー時の再送も無効。両条件とも API の出力上限は1呼び出し8,192トークン。
- ゲーム32/36、各ゲーム群10/12、全課題が各2/3、合格試行の提示までのP90が150秒以内。生成を3反復並列で行い、両条件の生成が終わってから同じChromiumで採点した。

## 再現と記録

`eval/out/replay-2026-11-11/` に実行設定、凍結時の照合値、変更前ソースのコピー、各試行の提示・保存・再生記録、API使用量、採点を保存した。基準版は変更前のソースのコピーから、候補版は照合した作業ツリーから実行する。

```sh
bun eval/replay/grade.ts --self-test --root eval/out/replay-2026-11-11 --port 4964
bun eval/p3/run.ts --suite replay --cond A --review off --run-dir <root>/baseline-r1 --host-port 4972 --live-config <config> --max-calls 42
bun eval/p3/run.ts --suite replay --cond A --review replay --run-dir <root>/candidate-r1 --host-port 4982 --live-config <config> --max-calls 42 --live-evaluator-config <config> --max-eval-calls 13
bun eval/replay/grade.ts --root <root> --run candidate-r1 --port 5022
bun eval/replay/compare.ts <root>
```

## 結果

| Luna low | 基準版 | 操作の再生あり |
| --- | ---: | ---: |
| ゲーム合格 | 36/36 | 36/36 |
| 新規制作 | 12/12 | 12/12 |
| 部分修正 | 12/12 | 12/12 |
| 不具合修復 | 12/12 | 12/12 |
| 非ゲーム | 3/3 | 3/3 |
| 提示・保存 | 39/39 | 39/39 |
| 合格試行の提示までのP90 | 18.0秒 | 23.3秒 |
| 制作／独立判定のAPI呼び出し | 42／0 | 42／24 |

両版とも全課題3/3で、Luna low の今回の作品品質基準を満たした。Chromium 141.0.7390.37 で採点した。候補版では42ターン中24ターンで手順を測定し、18ターンは測定できる手順がなかった。独立判定は課題全体で最大1回だった。独立判定から修正に進んだ試行は0件。基準版が全件合格したため、この課題セットで改善幅は測れない。P90はサーバー受付から候補提示までの値で、5.3秒増えた。

両版に使った新しい課題は、固定された画面と入力から仕様を確認できる2D作品に絞った。この結果を、前回31/36だった課題や複雑な物理・描画での品質改善として扱わない。

## 既知の不具合での再生確認

未使用課題では修正が発生しなかったため、既知のジャンプ不具合を持つ以前の保存版を初回候補にした。操作手順はこの確認用に用意し、Luna low の独立判定と制作の修正を各1回行った。前後で同じ手順と seed を使った。ChromiumでSpaceから350ms後の上昇量は119.5pxから81.5pxになり、800ms後は画面外から元の位置への着地に変わった。この確認は36件の集計から外し、`eval/out/replay-2026-11-11/regression.json` に残した。
