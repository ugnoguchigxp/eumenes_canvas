# 作品づくりの落とし穴（症状・原因・直し方）

制作担当に渡す付録。実際に起きて、原因を確かめ、直し方を確かめたものだけを載せる。追記するときは、同じ 3 点（症状・原因・直し方）と、確かめた場所を書く。

## 共通

| 症状 | 原因 | 直し方 |
| --- | --- | --- |
| キーを押してもジャンプしない・入力した直後の動きが消える | 入力のたびに `frame(t, 0)` が呼ばれる。`dt = 0` で重力・着地の判定を進めると、与えた初速がその場で消える | `if (dt > 0) update(dt / 1000);` の形にする。または `frame` の代わりに `update(t, dt)` と `draw(t)` を返す（`update` は `dt > 0` のときだけ呼ばれる） |
| キーを連打すると動きが速くなる | `frame` が呼ばれた回数で進めている（入力のたびに余分に 1 回呼ばれる） | 進行は `dt`（経過 ms）で計算する。フレーム数で数えない |
| Space・R が効かない環境がある | `ev.key` だけ、または `ev.code` だけを見ている | `ev.code === "Space" \|\| ev.key === " "` のように両方で受ける |
| 起動しない（`canvasApp.start は 1 回だけ呼べる`） | 契約の例示コードを作品に繋げた | 作品の全文に `canvasApp.start(` が 1 つだけあることを確かめる |
| 幅を変えると画面が欠ける・単色になる | 寸法を起動時に 1 回だけ読んでいる | レイアウトは毎フレーム `api.width`・`api.height` から計算する |
| 同じ操作でも結果が毎回違う | `Math.random`・`Date.now` を進行に使っている | 乱数は `api.random()`、時間は `frame` の `t`・`dt` |

## 3D（Three.js）

| 症状 | 原因 | 直し方 |
| --- | --- | --- |
| 何も映らない（単色） | WebGL の面を表示に出していない | `api.canvas3d` に描く（`new THREE.WebGLRenderer({ canvas: api.canvas3d })`）。自分で作った `OffscreenCanvas` に描いたときは、毎フレーム `api.ctx.drawImage(その面, 0, 0, api.width, api.height)` で写す |
| 指定した色と違う色で出る | 照明・陰影で色が変わった | 色が指定された要素は `MeshBasicMaterial` にする |
| 縦横比が崩れる・ぼやける | `resize` でカメラと描画の寸法を更新していない | `resize(w, h, dpr)` で `renderer.setPixelRatio(dpr); renderer.setSize(w, h, false); camera.aspect = w / h; camera.updateProjectionMatrix();` |
| 模様に放射状の継ぎ目が出る | 角度を `atan` で取り、±π で値が飛ぶ | 回転した座標で値を取る（角度そのものを使わない） |
| `TextureLoader`・`GLTFLoader` が動かない | URL からの読み込みは通信なので使えない | 形・色・テクスチャはコードで作る（`CanvasTexture`・`DataTexture`・`api.decodeSVG` の画像） |

## 物理（cannon-es）

| 症状 | 原因 | 直し方 |
| --- | --- | --- |
| ゆっくり転がる玉が坂の途中で止まる | 眠り（sleep）が、遅い物体を止めた | `world.allowSleep` を使わない |
| 玉が細い壁・床をすり抜ける | `SAPBroadphase` が静的な細い箱との接触を取りこぼした／刻みが粗い | 既定の broadphase（`NaiveBroadphase`）を使う。刻みを 1/120 秒にする。壁を厚くする |
| 玉が通路で詰まる | 通路の幅が玉の直径より狭い | 幅は直径より大きくする（直径 0.5 なら 0.6 以上） |
| 重なって出た玉がはじけ飛ぶ | 出口に玉があるのに次を出した | 出口が空いてから出す |
| 入力のたびに物理が進む | `dt = 0` で `world.step` を呼んだ | `world.step(1 / 60, dt / 1000, 5)` は `dt > 0` のときだけ呼ぶ |

## HTML の描画（`api.decodeSVG`）

| 症状 | 原因 | 直し方 |
| --- | --- | --- |
| 復号が失敗する | XHTML として正しくない（閉じていないタグ、生の `&`） | タグは閉じる。`&` は `&amp;`。ルートの `<svg>` に `width`・`height` を書く |
| 毎秒の上限を超えて失敗する | 毎フレーム作り直している | 内容が変わったときだけ作り直す |
| 画像・外部の書体が出ない | SVG は画像として読まれ、外部の資源を読まない | 文字は端末の書体で描かれる前提にする。図形は CSS で描く |
